DeepSeek Harness 的“额度与用量”现在会按 dsh 实际选择的模型路由显示余额：`deepseek-account` 显示平台账号的充值／赠送余额，`deepseek-official` 显示 API 密钥余额，其他服务商仍按各自凭据查询。

The DeepSeek Harness quota panel now reads the route dsh actually selected: `deepseek-account` shows the platform account's recharge and bonus wallets, `deepseek-official` shows the API-key balance, and other providers keep their own credentials.

## 修复内容 / Fixes

- **模型选择器解析 / Selector parsing**：dsh 0.2.2 的 ACP 模型值是 `["provider","model"]` JSON 选择器，旧解析把它当成普通模型名，导致“当前 dsh 模型路由无法确定账号”。现在按 JSON 对解析，并兼容 `provider/model` 与裸模型 id。
- **按路由查询 / Route-aware lookup**：`deepseek-account` 使用平台账号 grant 查询充值／赠送余额；`deepseek-official`（以及旧的 `deepseek`）使用 `DEEPSEEK_API_KEY` 查询账户余额；`llm-pi-ai/<provider>` 路由沿用原服务商查询。
- **凭据边界 / Credential boundaries**：只向 DeepSeek 官方域名发送凭据；账号 grant 的 issuer 不匹配、未登录或缺少 API 密钥时给出明确提示；不会调用模型或创建对话。
- **回归 / Regression**：新增选择器解析、两条 DeepSeek 路由分派、旧格式兼容、未知路由无网络请求及真实凭据只读验证。

## 安装 / Installation

1. 下载 / Download `zotero-agent-zh-CN-0.15.2.13.xpi`。
2. Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 XPI，按提示重新启动。
3. In Zotero, open **Tools → Plugins → Install Plugin From File…**, select the XPI and restart if prompted.

附件 / Assets：

- `zotero-agent-zh-CN-0.15.2.13.xpi`：安装包 / installable plugin。
- `zotero-agent-zh-CN-0.15.2.13-source.zip`：与版本标签一致的完整源码 / complete source matching the release tag。
- `SHA256SUMS.txt`：上述两份文件的 SHA-256 / SHA-256 checksums for both files。
