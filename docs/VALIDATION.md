## 上游完整测试的限制

保留了上游测试文件，并提供 `npm run test:upstream`，使用显式文件枚举避免 Windows 对带单引号 glob 的处理导致“0 tests”。该命令不属于默认的汉化界面检查。

在当前 Windows 环境中，上游后端测试中多项依赖创建符号链接，遇到 `EPERM`；另有 POSIX/Windows 路径分隔符断言差异。未为运行测试而修改系统安全设置，也未将完整上游测试标记为通过。部分集成测试还依赖原仓库环境、真实 Zotero 或模型后端；本次没有运行这些集成及联网模型测试。

插件体积检查按这个衍生版本明确设置上限：启动脚本仍为 12,000 字节，侧栏脚本为 800,000 字节，XPI 为 300,000 字节。相较上游阈值的增加用于中文词典、本地化代码、额度适配器及随包分发的来源与许可文件；具体改动记录在 `test/budget.test.ts`。
